Erros comuns

Cada conta tem um erro. Ache antes de abrir.

Onde está o erro? (1)x2=x
Ver o erro
O erro
Para x<0, a raiz dá o oposto de x: a raiz nunca é negativa.
Certo
x2=|x| (ver B02 e B13); o gráfico de x2 é o V.
Conferência
Com x=−3: 9=3≠−3.
Onde está o erro? (2)O gráfico de 1x corta o eixo x bem longe, e corta o eixo y em 0.
Ver o erro
O erro
1x nunca é 0, e x=0 está fora do domínio.
Certo
Não corta nenhum eixo.
Conferência
11000=0,001≠0; 10 não existe.
Onde está o erro? (3)x3 é par, como x2: (−x)3=x3.
Ver o erro
O erro
Cubo de negativo é negativo.
Certo
(−x)3=−x3: ímpar.
Conferência
Com x=2: (−2)3=−8≠8.
Onde está o erro? (4)Elevar ao quadrado sempre aumenta: x2>x.
Ver o erro
O erro
Entre 0 e 1, o quadrado é menor.
Certo
x2<x para 0<x<1.
Conferência
Com x=0,5: 0,25<0,5.
Onde está o erro? (5)Zeros −1 e 3, então P(x)=(x−1)(x+3).
Ver o erro
O erro
O número no fator tem o sinal contrário ao do zero.
Certo
P(x)=(x+1)(x−3)
Conferência
Com x=−1: (−1−1)(−1+3)=−4≠0.
Onde está o erro? (6)x-2 é negativa, porque o expoente é negativo.
Ver o erro
O erro
O sinal do expoente manda inverter, não dá o sinal do valor: x-2=1x2.
Certo
x-2=1x2>0 para todo x≠0.
Conferência
Com x=2: 2-2=14>0; com x=−2: (−2)-2=14>0.
Onde está o erro? (7)x3/2 existe para todo x.
Ver o erro
O erro
O denominador 2 é o índice da raiz, e raiz de índice par só existe para x≥0.
Certo
x3/2=(x)3 só para x≥0.
Conferência
Com x=−4: (−4)3=−64 não existe em ℝ.
