Erros comuns

Cada conta tem um erro. Ache antes de abrir.

Onde está o erro? (1)12+14=16
Ver o erro
O erro
Somou em cima e embaixo. Antes de somar, o mesmo denominador.
Certo
12+14=24+14=34
Conferência
Em decimal: 0,5+0,25=0,75. E 16 é menor que 12: impossível.
Onde está o erro? (2)−22=4
Ver o erro
O erro
A potência vem antes do sinal: só o 2 é elevado ao quadrado.
Certo
−22=−(22)=−4; só (−2)2=4.
Conferência
−x2 em x=−2: −(−2)2=−4.
Onde está o erro? (3)(−3)(−2)(−1)=6
Ver o erro
O erro
Três fatores negativos: número ímpar, resultado negativo.
Certo
(−3)(−2)(−1)=−6
Conferência
Aos poucos: (−3)(−2)=6 e 6⋅(−1)=−6.
Onde está o erro? (4)235=103
Ver o erro
O erro
Inverteu a fração errada: o traço maior está acima do 5, e é o 5 que se inverte.
Certo
235=23⋅15=215
Conferência
0,666…÷5≈0,133 e 215≈0,133.
Onde está o erro? (5)4+64=6
Ver o erro
O erro
Cancelou uma parcela. Só se cancela fator, o que multiplica tudo.
Certo
4+64=104=52
Conferência
10÷4=2,5, e não 6. Com letras, é o erro x+33=x do B03.
Onde está o erro? (6)mmc(12,18)=6
Ver o erro
O erro
Achou o mdc: só os primos comuns, com o menor expoente. No mmc entram todos os primos, com o maior expoente.
Certo
12=22⋅3, 18=2⋅32:   mmc(12,18)=22⋅32=36
Conferência
6 não é múltiplo de 12. Já 36=3⋅12=2⋅18.
